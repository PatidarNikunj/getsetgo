Auto PiP test page

Pick a local video file (or use the generated clock), press play, then try each case below.

Checklist

  1. Switch tab with Ctrl+Tab or Cmd+Shift+]: PiP opens. Come back: PiP closes, video keeps playing here.
  2. Click another tab in the tab bar: PiP opens if Safari allows it without a gesture (see README).
  3. Cmd+Tab to another app or click another window: same as above.
  4. Cmd+T / Cmd+N / Cmd+H / Cmd+M: PiP opens, closes on return.
  5. Pause in the PiP window, then come back: video stays paused here.
  6. Close the PiP window while away, then come back: nothing re-opens.
